## О проекте

Проект представляет собой интернет-магазин, где можно продавать и покупать цифровые товары: плагины, скрипты, шаблоны, полезные утилиты.

### Что уже реализовано:

#### Задание 1 (предыдущее)
- Простой HTTP-сервер на Python (без фреймворков), который обрабатывает GET и POST запросы.
- Четыре статические страницы (Главная, Каталог, Категория, Контакты), свёрстанные с помощью Bootstrap.
- Обработка формы на странице контактов с выводом данных в консоль.

#### Задание 2 (текущее)
- Создан Django-проект `config`.
- Создано приложение `catalog`.
- Настроены маршруты (URL) и контроллеры (views).
- Реализованы два HTML-шаблона с наследованием (`base.html`, `home.html`, `contacts.html`).
- Подключён Bootstrap (через CDN).
- Реализована форма обратной связи на странице контактов: данные выводятся в консоль, пользователь видит сообщение об успешной отправке.
- Соблюдены правила GitFlow: ветки `main`, `develop`, `feature/django_homework`, создан pull request.
